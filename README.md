# 📋 Gerenciador de Tarefas

Aplicação web desenvolvida com **HTML, CSS e JavaScript**, com o objetivo de organizar tarefas do dia a dia de maneira simples e prática.

O projeto foi desenvolvido durante meus estudos em Desenvolvimento Front-end, colocando em prática conceitos de manipulação do DOM, eventos, arrays, funções, validação de formulários e armazenamento local de dados.

## 🚀 Funcionalidades

- ✅ Cadastrar tarefas com descrição, categoria, prioridade e data de conclusão.
- ✅ Marcar tarefas como concluídas ou retornar ao status pendente.
- ✅ Excluir tarefas mediante confirmação.
- ✅ Filtrar tarefas por status e categoria.
- ✅ Visualizar indicadores de tarefas totais, pendentes e concluídas.
- ✅ Validar os campos obrigatórios do formulário.
- ✅ Armazenar tarefas no navegador utilizando `localStorage`.
- ✅ Utilizar a aplicação em computadores e dispositivos móveis.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e organização da página.
- **CSS3:** estilização, Flexbox e responsividade.
- **JavaScript:** lógica de funcionamento, eventos e manipulação do DOM.
- **localStorage:** persistência dos dados no navegador.

## 💻 Como executar

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Cadastre suas tarefas e utilize as funcionalidades disponíveis.

Não é necessário instalar bibliotecas ou dependências externas.

## 🧠 Conceitos aplicados

Durante o desenvolvimento, foram utilizados:

- Manipulação do DOM com `getElementById`, `createElement` e `appendChild`.
- Eventos com `addEventListener`.
- Arrays e objetos JavaScript.
- Estruturas condicionais e de repetição.
- Funções para organização do código.
- Validação de formulários.
- Conversão de dados com `JSON.stringify()` e `JSON.parse()`.
- Persistência de dados com `localStorage`.
- Layout responsivo com Media Queries.

## 🎨 Interface

A aplicação utiliza um tema escuro com detalhes amarelos, buscando oferecer uma interface simples, organizada e de fácil utilização.

As tarefas concluídas recebem uma aparência visual diferente, facilitando a identificação do seu status.

## 📚 Aprendizados

Este projeto contribuiu para o desenvolvimento das minhas habilidades em JavaScript, especialmente na integração entre HTML e JavaScript, no gerenciamento de eventos e na atualização dinâmica dos elementos da página.

Também permitiu compreender como armazenar informações no navegador sem a necessidade de um banco de dados externo.
